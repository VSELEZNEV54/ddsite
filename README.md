# ddsite

Сайт Darlein Defense, статический.

- Корень — главная в новом дизайне: `index.html`, стили в `css/`, скрипты в `js/`, фото в `img/`, ролик первого экрана в `video/`, логотипы в `assets/`.
- `prototype/` — прежний прототип целиком. Остальные разделы пока открываются оттуда; старые адреса страниц ведут туда через `404.html`.

Открыть `index.html` в браузере можно и без сервера.
