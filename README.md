# ddsite

Сайт Darlein Defense, статический.

- Корень — все 27 страниц в финальном дизайне: главная `index.html`, «О компании», «Проекты», «Партнерам», «Инвесторам», «Карьера», «Новости» и статья, «Контакты», юридические документы, «Спасибо», 404, карта сайта и 14 страниц продуктов (`dropfield.html`, `agata.html` и др.). Стили в `css/`, скрипты в `js/`, фото в `img/`, логотипы в `assets/`.
- Финальный дизайн — скругленный стиль по брендбуку, утвержден заказчиком 18.10.2026: `css/brand.css` подключен на всех страницах последним, `js/brand.js` (пиктограммы брендбука) — сразу после `js/base.js`.
- Фото в `img/`: `b-*` — кадры брендбука, `pr-*` — продукты, `dr-*` — направления, `st-*` — блоки страниц. Остальные кадры сгенерированы и приведены к тону брендбука скриптами `DD/design-tools/photo_prompts.py` и `grade_photos.py`. Людей и лиц в кадрах нет.
- Шрифты Geist и Tektur лежат в `fonts/`, сторонние сервисы страницы не подключают.
- Английская версия — в `en/` и `js/en/`, собирается из русской скриптом `DD/design-tools/build_en.py` по словарю `DD/design-tools/en/` (раздел 19 правил стиля). Русскую версию правят первой, английскую пересобирают. Английская версия обновлена 27.10.2026 и совпадает с русской.
- Правила стиля и каталог компонентов — `docs/style-guide.md`. Новые страницы делаются по ним.
- Внутренние страницы собирает `DD/design-tools/build_site_pages.py`, ассеты брендбука — `DD/design-tools/brand_assets.py` (оба вне репозитория). Тексты страниц компании и продуктов по правкам заказчика 25.10.2026 — в `DD/design-tools/content/` (раздел 20 правил стиля). Правки разметки вносятся в скрипт, затем страницы пересобираются.
- `prototype/` — прежний прототип целиком, архив и источник текстов. Для навигации он не нужен: меню, подвал и ссылки ведут на страницы в корне.

Открыть `index.html` в браузере можно и без сервера; шрифты при открытии файла напрямую некоторые браузеры не подгружают, для проверки лучше локальный сервер (`python3 -m http.server`).
