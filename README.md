# ddsite

Сайт Darlein Defense, статический.

- Корень — все 28 страниц в финальном дизайне: главная `index.html`, «О компании», «Проекты», «Партнерам», «Инвесторам», «Карьера», «Новости» и статья, «Контакты», юридические документы, «Спасибо», 404, карта сайта и 14 страниц продуктов (`dropfield.html`, `agata.html` и др.). Стили в `css/`, скрипты в `js/`, фото в `img/`, логотипы в `assets/`.
- Финальный дизайн — скругленный стиль по брендбуку, утвержден заказчиком 18.10.2026: `css/brand.css` подключен на всех страницах последним, `js/brand.js` (пиктограммы и кадры брендбука) — сразу после `js/base.js`.
- Правила стиля и каталог компонентов — `docs/style-guide.md`. Новые страницы делаются по ним.
- Внутренние страницы собирает `DD/design-tools/build_site_pages.py` из текстов прототипа, ассеты брендбука — `DD/design-tools/brand_assets.py` (оба вне репозитория). Правки разметки вносятся в скрипт, затем страницы пересобираются.
- `prototype/` — прежний прототип целиком, архив и источник текстов. Для навигации он не нужен: меню, подвал и ссылки ведут на страницы в корне.

Открыть `index.html` в браузере можно и без сервера.
