# ddsite

Сайт Darlein Defense, статический.

- Корень — страницы в новом дизайне: главная `index.html`, «О компании» `company.html`, «Проекты» `projects.html`. Стили в `css/`, скрипты в `js/`, фото в `img/`, логотипы в `assets/`.
- Правила стиля и каталог компонентов — `docs/style-guide.md`. Новые страницы делаются по ним.
- `prototype/` — прежний прототип целиком. Разделы, которые еще не переделаны (партнерам, инвесторам, карьера, новости, контакты, страницы продуктов), открываются оттуда; старые адреса страниц ведут туда через `404.html`.

Открыть `index.html` в браузере можно и без сервера.
